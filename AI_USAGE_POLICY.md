# AI Usage Policy

We do not accept contributions generated by AI. 

This includes, but is not limited to:
- Chat assistants and completion tools (e.g., ChatGPT, Claude, or GitHub Copilot)
- Autonomous coding agents
- Local LLMs

## Reasoning

- Licensing: Small-text was developed with a strict stance on respecting software licenses.
  With AI-generated code, it can't be ruled out that some generated code is a reproduction of existing code that is
  under an incompatible license.
- Ownership: In several jurisdictions, AI-generated code may not quality for copyright protection, on which the MIT license relies.
- Review: Finally, AI-assisted coding can often lead to code that looks good but has subtle bugs which are harder to spot. 
  Given the asymmetry that human reviewing is more expensive that AI-assisted coding, this could lead to more problems that it would benefit this repository.

As you can guess from the topic of this repo, we don't have an anti-AI stance,

## Consequences of a violation

Pull requests suspected to be AI-generated will be closed without further review.
